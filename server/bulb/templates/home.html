What this system supports

  • Manual control for turning bulbs on or off on demand.
  • Brightness control with conflict-aware command handling.
  • One-time and recurring schedules with timezone-aware execution.
  • Role-based sharing for owners, admins, controllers, and viewers.
  • Power usage reporting across the life of the system.
  • User activity reporting for accepted, rejected, and overridden actions.

Main app areas

The system is organized around daily control, scheduling, access management, and reporting.

Dashboard

View a selected bulb, send manual commands, and get immediate status feedback.

  • On-demand control
  • Brightness updates
  • Current device status
  • Conflict and permission messages

Schedules and Access

Create timed actions and manage who can control or view each bulb.

  • One-time schedules
  • Weekly recurring schedules
  • Manage Access page
  • Role-based permissions

Reports

Review power history and user activity with filters and exports.

  • Power summaries
  • Activity filters
  • Conflict outcomes
  • CSV export

Core project capabilities

These match the main design goals for the smart light system.

1. On-demand power control

Turn the light on or off from the web interface.

2. On-demand brightness control

Adjust light output whenever the bulb is on.

3. Scheduling

Set one-time and weekly timed actions.

4. User privileges

Assign and manage access for other users.

5. Power reporting

Review power usage over any selected date range.

6. Activity reporting

Track user control actions and outcomes over time.

7. Conflict management

Apply centralized rules for overrides and rejected actions.

8. Web-based interface

Use one consistent interface for control, scheduling, sharing, and reports.
